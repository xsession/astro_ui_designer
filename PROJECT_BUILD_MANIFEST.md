## Source-package scope

This ZIP is a complete runnable **source project**. It contains the browser designer, local host, project model, plugins, VS Code source mirror, round-trip runtime, tests and documentation.

Historical generated release outputs such as old VSIX binaries, previous visual-regression PNGs and old generated sample ZIP archives are not required to build/run the project and are intentionally not used as authoritative source inputs. They can be regenerated from source.

Because the connected GitHub App rejects write operations with HTTP 403, integration was performed locally against the pinned public repository state rather than committed to the remote repository.
