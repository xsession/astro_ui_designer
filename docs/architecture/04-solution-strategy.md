# 4. Solution strategy

- Maintain one normalized semantic project model.
- Keep canvas editing CSS-native and responsive by default.
- Use stable IDs as the cross-subsystem identity primitive.
- Isolate host privileges behind workspace bridges.
- Isolate framework semantics behind round-trip adapters and neutral IR.
- Treat source write-back as a reviewed transaction with fingerprints/checkpoints.
- Interpret project behavior declaratively for deterministic simulation.
- Expose semantic MCP tools rather than generic OS authority.
- Generate exact reference documentation from registries/source where practical.
