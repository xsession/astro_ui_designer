# 5. Building block view

## Level 1 blocks

1. **Designer shell** — modes, documents, selection, commands and dock orchestration.
2. **Semantic model** — project/page/node/component lifecycle and migration.
3. **Visual editing subsystem** — rendering, direct manipulation, responsive styles, CSS/animation/effects.
4. **Specialist workbenches** — functional inspectors/panels around the model.
5. **Round-trip/interchange** — adapters, neutral IR, source identity, Draw.io/QML/platform IO.
6. **Verification** — validation, audits, Component Lab and deterministic simulation.
7. **Host bridge** — standalone workspace HTTP API and VS Code extension bridge.
8. **Agent integration** — project-scoped MCP and Hermes skill.

See [C4 component view](../c4/3-components.md) and [module guide](../contributor/MODULE_GUIDE.md).
