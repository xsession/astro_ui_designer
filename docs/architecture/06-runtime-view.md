# 6. Runtime view

Key scenarios are documented as sequence-oriented runtime diagrams:

- import existing project → detect adapter → build source mappings → create designer project;
- direct manipulation → responsive geometry mutation → validate/recovery snapshot → render;
- visual→source sync → plan → fingerprint/staleness check → apply → checkpoint/audit;
- simulation → create session → dispatch event → condition/action interpreter → state/navigation → render summary;
- MCP request → load contained project → validate semantic args → mutate/read → atomic write or in-memory session → response.

See `docs/c4/diagrams/` for rendered runtime views.
