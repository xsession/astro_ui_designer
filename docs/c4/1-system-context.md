# C4 C1 — system context

**Person:** UI/HMI developer or designer-engineer.

**System:** Astro UI Designer — visual/source IDE, simulation environment and project automation boundary.

**External systems:** local filesystem and Git, target framework runtimes/toolchains, VS Code, MCP agent client, browser, interchange/design tools and generated application deployment environment.

The user edits a semantic project through the visual IDE. The system reads/imports source through controlled adapters, writes reviewed patches or generated outputs, and can simulate only its declarative design behavior. External target runtimes remain authoritative for final application execution.
