# C4 C3 — component view

Inside the Designer Web App, the principal components are: shell/commands, project model, component registry, canvas renderer, direct manipulation/manual layout, functional workbenches, CSS/color/animation editors, page lifecycle, plugin API, simulation interpreter, platform interchange, round-trip bridge/UI and workspace client.

Inside the Round-trip Engine, the principal components are backend metadata/detection, source identity/fingerprints, neutral IR, import/export conversion, review-plan/history/checkpoint state and framework adapters including QML/pwtk.

Inside the MCP Server, the request dispatcher uses a narrow project service and shared model/simulation/arrangement modules rather than duplicating editor semantics.
