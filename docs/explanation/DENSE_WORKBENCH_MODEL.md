# Dense workbench UI model

Density is useful when experts repeatedly compare multiple properties, source, hierarchy and diagnostics. Overwhelm appears when every command has equal visual priority. The UI therefore uses progressive disclosure: frequent file/edit/mode operations stay close to the canvas while specialist tools live in named docks/workbenches, with relocatable layout and editable hotkeys for expert optimization.

The 2.19 cleanup reduces visual weight without reducing information capacity. Inspector disclosure state persists, active tabs use restrained emphasis, and lower-frequency commands are grouped into menus.
