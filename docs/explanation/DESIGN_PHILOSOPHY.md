# Design philosophy

Astro UI Designer combines a dense engineering workbench with source ownership. It rejects two extremes: a purely visual proprietary runtime where the editor owns execution, and a purely textual workflow that offers no direct design-system or spatial tools.

The designer therefore uses explicit project metadata for what benefits from modeling—components, variants, interactions, tokens, source identity, tests—while exporting ordinary code and preserving unsupported imported source. Dense docks and progressive disclosure support expert workflows without forcing all specialist tools onto the center canvas.
