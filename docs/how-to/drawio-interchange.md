# How to use Draw.io / diagrams.net interchange

Import `.drawio`, compatible XML or Draw.io SVG through Interchange. Multi-page files are supported. The importer handles common geometry, labels, basic style, groups, images and preserved connector metadata. Export produces standard uncompressed diagrams.net XML.

Complex vendor-specific stencils, HTML labels and connectors may be preserved as metadata or reduced to the closest editable designer representation. The master architecture file in `docs/c4/diagrams/astro-ui-designer-master.drawio` intentionally uses conservative diagrams.net shapes to stay portable.
