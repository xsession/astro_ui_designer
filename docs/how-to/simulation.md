# How to verify behavior with simulation

Use F7 or the Simulation workbench. Choose page or project scope, a start page/flow and viewport. Trigger click, hover, focus, input/submit and modeled delay events. Inspect navigation history, overlays, state variables and event log. Reset before reproducing a bug so the starting state is deterministic.

Simulation evaluates only the designer's declarative action/condition model. Run the exported application for behavior that depends on arbitrary framework code or external services.
