# Glossary

**Artboard** — center design coordinate surface for a page/component.

**Breakpoint layer** — style object that overrides `style.base` for a responsive breakpoint.

**Designer project** — serialized semantic model (`designer-project.json` or `.astro-ui.json`).

**Freeform** — scoped container where explicit position geometry is the intended layout model.

**Neutral IR** — framework-neutral representation used by conversion/round-trip adapters.

**Round-trip** — controlled synchronization between source files and designer model.

**Source identity** — stable information that lets an adapter relocate the exact source construct corresponding to a designer node.

**Fingerprint** — deterministic source-content hash used for stale-plan detection.

**Workbench** — specialist dock panel for a focused task such as CSS, Simulation, Git or Round-trip.

**Simulation session** — ephemeral deterministic state used to interpret declarative project behavior.

**Provider boundary** — interface exists but provider-specific service/runtime is intentionally external.
