# Tutorial: responsive design to Astro export

Create Desktop/Tablet/Mobile breakpoints, use Row/Grid/Container instead of absolute geometry for the main layout, apply breakpoint-local typography and spacing, run the responsive audit, then export Astro. Inspect generated CSS for base plus responsive selectors. If a Freeform/HMI region is necessary, keep it scoped inside a responsive parent so page-level layout remains adaptive.

Use this tutorial together with [How to work with breakpoints](../how-to/responsive-breakpoints.md) and [Direct manipulation model](../explanation/DIRECT_MANIPULATION_MODEL.md).
