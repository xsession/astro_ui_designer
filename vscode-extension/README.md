# Astro UI Designer VS Code 2.19.0

Embeds the full Astro UI Designer 2.18 experience in a VS Code webview with workspace-aware source access.

Highlights:

- advanced multi-selection/manual editing: marquee, group transforms, align/distribute/tidy, layer order, group/ungroup, flip, lock, rulers/guides and smart snapping
- F7 page/project Simulation mode with state, navigation, overlays, flows, hotspots and event log
- native **Import Existing Project…** folder chooser with adapter auto-detection/review
- Qt Quick/QML plus Astro, React, Vue, Svelte, Vanilla JS/TS, Tkinter, NiceGUI, LVGL and pwtk round-trip support
- 42 relocatable/floating workbenches, editable hotkeys and Draw.io interchange
- source/workspace API, Git helpers and reviewed source round-trip

The embedded `designer/` source is synchronized with the standalone editor for release validation.
